# Architecture multilingue (préparation)

**État** : seul le français est publié. L'arabe (RTL) est prévu et déclaré dans `src/i18n/config.ts` avec `enabled: false`.

## Principes

1. Aucune traduction partielle n'est mise en ligne : une langue est activée uniquement quand son dictionnaire (`src/i18n/<code>.ts`) est complet et que le contenu éditorial minimal existe dans cette langue.
2. Les attributs `lang` et `dir` de `<html>` viennent de la configuration du site ; le passage en RTL se fera par `dir="rtl"` et les utilitaires logiques Tailwind (`ms-`, `me-`, `ps-`, `pe-`, `start`, `end`) — à privilégier dès maintenant dans les nouveaux composants.
3. Les URL resteront sans préfixe pour le français (`/guides/...`) ; l'arabe utilisera le préfixe `/ar/...` avec `hreflang` réciproques.
4. Les contenus éditoriaux (articles) porteront une colonne `locale` et un `translationOf` (id de l'article source) lors de l'activation ; le catalogue conserve des données constructeur communes et un bloc éditorial par langue.

## Checklist d'activation de l'arabe

- [ ] Dictionnaire `src/i18n/ar.ts` complet (mêmes clés que `fr.ts`, vérification par test de typage).
- [ ] Police arabe auto-hébergée (licence vérifiée) et chargement conditionnel.
- [ ] Revue RTL de chaque composant de layout (header, mega-menu, tiroir mobile, tableaux du comparateur).
- [ ] Pages légales et méthodologie traduites et relues.
- [ ] Au moins 5 guides traduits et validés.
- [ ] `hreflang`, sitemaps par langue, `robots` inchangé.
