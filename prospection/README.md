# Prospection domaines — FoodPark.net · LateLets.com · BikeFitting.net

Date : 22 septembre 2026. Méthode : (1) sondage de toutes les extensions homonymes (foodpark.*, latelets.*, bikefitting.*) pour trouver les sociétés qui utilisent déjà le nom ; (2) recherche des acteurs sectoriels ; (3) extraction des contacts directement sur les sites officiels (pages contact / mentions légales / fiches Play Store / annuaire IBFI).

Légende « Vérif. » :
- **Site** = e-mail/téléphone lu directement sur le site officiel de l'entreprise.
- **Registre** = source officielle tierce (Companies House, Play Store, annuaire IBFI, Shimano).
- **Web** = trouvé via résultats de recherche, non relu sur le site (à re-vérifier avant envoi).

Fichier tabulaire : `prospects.csv` (même contenu, exploitable dans un CRM).

## 3. BikeFitting.net
