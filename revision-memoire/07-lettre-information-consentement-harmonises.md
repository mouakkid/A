# Lettre d'information et formulaire de consentement — versions harmonisées (PROJET)

**Version :** 1.0 — 7 août 2026 · **Statut : PROJET à valider** (auteur → encadrante → DPO/TBS → dossier CNDP). Ces textes remplacent les versions contradictoires relevées par l'audit (§5.1) et résolvent les cinq contradictions : accès aux enregistrements, transit cloud, anonymisation vs pseudonymisation, second codeur absent des destinataires, consentement oral vs écrit. Les champs `[…]` sont à compléter ; les choix marqués `[décision AF‑07]` doivent être arbitrés avant validation.

**Règle de cohérence :** une fois validées, ces versions font foi ; le corps du mémoire, la fiche logistique et les annexes doivent s'y aligner mot pour mot sur les points suivants : liste des destinataires, procédure d'enregistrement, terme « pseudonymisation », règle de consentement, durées, point de non‑retrait.

## C. Procédure d'exception : consentement oral

**Règle par défaut : consentement écrit** (formulaire B, deux exemplaires). L'exception orale n'est admise que si l'écrit est matériellement impossible (ex. : entretien à distance sans moyen d'échange de documents) `[décision AF‑07 : maintenir ou supprimer l'exception]` :

1. Le chercheur lit intégralement la lettre d'information ;
2. Le consentement est recueilli **oralement et enregistré en tête d'enregistrement**, en reprenant une à une les déclarations du formulaire B (avec les OUI/NON explicites) ;
3. La lettre d'information est transmise au participant (courriel) avec accusé ;
4. L'exception est consignée au journal de terrain (motif, date) ;
5. Le formulaire écrit est régularisé dès que possible si un contact ultérieur le permet.

## D. Points d'harmonisation à répercuter dans le mémoire (rappel)

| Point | Ancien état (contradictoire) | État harmonisé |
|---|---|---|
| Accès aux enregistrements | « Seul chercheur » (lettre/consentement) vs encadrante autorisée (corps/fiche logistique) | Liste unique du §5 de la lettre, identique partout |

| Anonymisation | Terme employé pour un dispositif de pseudonymisation | « Pseudonymisation » partout, avec explication en langage clair |
| Second codeur | Prévu en analyse mais absent des documents d'information | Destinataire déclaré (lettre §5, formulaire B) sous engagement de confidentialité |
| Consentement oral vs écrit | Deux régimes concurrents non articulés | Écrit par défaut + procédure d'exception C encadrée |
